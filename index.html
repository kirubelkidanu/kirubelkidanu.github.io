GitHub Pages Image Setup Guide

How to add project screenshots to your GitHub repo

Your HTML is already configured with direct filenames. Follow these 3 easy steps on GitHub to display your actual screenshots:

01. Open your repository on GitHub (the one hosting your website).
02. Click Add file → Upload files in the root folder (where index.html is).
03. Upload your screenshots using these exact filenames:
Required filenames Match exactly
  • inventory.png Laravel ERP
  • clinic.png Speech Clinic
  • hotel.png Hotel Booking
  • kirastore.png Kira WooCommerce
If an image isn't uploaded yet, a modern fallback gradient is shown automatically.
